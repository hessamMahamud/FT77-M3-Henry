Perfecto. Empecemos por mobile-first.
¿Por qué mobile-first?
Porque las pantallas chicas son el caso más restrictivo. Si funciona ahí, escalar es fácil.
¿Y el viewport?
El meta viewport le dice al navegador móvil que use el ancho real del dispositivo.
¿Flexbox o Grid?
Flexbox para una dimensión (como este chat). Grid para dos dimensiones.
¿Cuándo usar rem y cuándo px?
Rem para spacing y tipografía. Px solo para bordes finos y sombras.
